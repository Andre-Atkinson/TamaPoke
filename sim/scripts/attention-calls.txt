# Attention calls (#9). A need that drops below 25 calls once, and a call is not a touch.
#   A. dimmed screen: brightens for 15 s, then the real idle applies (dim, then off on schedule)
#   B. timed-out screen: a 15 s "peek" with the "!" bubble beside the pet, touch still locked
#      (the auto touch lock is on); a view left open is closed first; PWR turns it on for real
#   C. quiet hours (22:00-07:00 with bedtime off): silent and dark
#   D. screen turned off with PWR: the call chirps and the panel stays dark
#   E. pocket lock (three quick PWR presses): the call is spent silently, panel stays dark
# A manual check: run it and read the log and the shots; nothing compares them automatically.
#   tools/sim.sh --script attention-calls --serial-log calls.log --out shots/
# Each call is one serial line: "call hygiene: brighten chirp", "call food: peek chirp",
# "call joy: silent (quiet)", "call energy: dark chirp", "call hygiene: silent (locked)".
# "serial HEALTH" lines only stamp the simulated time ("up=...s") into the log.
# The shots do not show brightness (the simulator draws the same picture at any level).
