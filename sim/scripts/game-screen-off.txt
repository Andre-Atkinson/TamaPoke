# A Play minigame when the screen goes dark (#94). For both boards, both languages, by day
# and by night:
#   tools/sim.sh --board 175c --lang en --script game-screen-off --out shots/
#   tools/sim.sh --board 175 --lang pt --clock "2026-11-16 21:00" --script game-screen-off --out shots/
# PWR (and on the 1.75C the pocket lock, three presses) ends a minigame at once and the pet
# gets what its score so far earns (Pet::playGame), with no result screen and no sound; a
# game nobody touched pays nothing. The screen comes back on to the creature. The serial log
# (shots/serial.log) has one "Play:" line per game, in this order (the scores and speeds
# differ from run to run: the games' dice follow the time and the board):
#   Play: song untouched (screen off)           1. nobody touched it: nothing paid
#   Play: peek score=6 speed=+1 (screen off)    2. played: paid its score so far
#   Play: keepy score=0 speed=+0                3. ran to its end: paid there, once; PWR on
#                                                  its result screen adds no line
#   Play: catch score=0 speed=+0 (screen off)   4. the pocket lock (one tap: played, so paid)
#   Play: peek score=14 speed=+3 (screen off)   5. the speed ribbon (shot 15: its banner)
#   Play: song score=0 speed=+0 (screen off)    6. the battery runs out mid-game
# What must hold on every run, which the expect steps below check (#99; tools/gate.sh runs
# this script on both boards and fails if one doesn't hold): line 1 says "untouched"; lines 2,
# 4, 5 and 6 end in "(screen off)"; line 3 does not (shot 08 is the keepy's result screen, paid
# at its end), and no line comes between 3 and 4; line 5 has speed=+1 or more (+1 completes
# the ribbon in shot 15). Each check looks at the lines printed since the check before it.
# Each section names its game with the simulator's "game" step, so the bag's dice don't
# decide which comes. The Play button is at (202, 404) and its strip's Poke Ball at
# (169, 320) (#13); a game shows its title card for 1.2 s, then plays. In Peekaboo a tap on
# an empty bush costs nothing, so the taps go round the five bushes (game_peek.h) and catch
# the pet as it pops up.

# 4. The pocket lock (three presses) on a game with one tap (Berry Catch): on the 1.75C the
# lock hint, then dark, and three more presses unlock. The 1.75 has no lock: it reads PWR
# every 250 ms, so quick presses merge and each three toggle the screen once or twice.
# Either way the first dark ends the game, paid; a tap on nothing then wakes a screen the
# 1.75 left dark (on a lit one it does nothing).
