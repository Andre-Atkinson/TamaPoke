# The Portuguese accented capitals (#85): every upper-case string that uses one of the
# capitals ptglyphs.h draws (A' A~ E' I' O' O^ O~), and two names for the player in mixed
# case, which also show the four no UI string uses (A` A^ E^ U').
# By day (10:00): all of it. By night (22:00, shots 13-18): the card pages, the status
# line, the release dialog and the 12-rep hold result, the only screens here whose ink
# or colours change with the night. The banners (MEDALHA!, OTIMO!) and the clock prompt
# (QUE HORAS SAO?) are not shot at night: they are drawn in fixed colours (UI_BAR_WARN
# and UI_INK in drawCelebration, UI_BG_DAY and UI_INK in renderClock), the same day and
# night. The name bubbles are shot by day only: their text is dark on white, day or night
# (drawSpeechBubble); only the outline follows the night ink.
# A manual check: run it in Portuguese on both boards and look at the shots.
#   tools/sim.sh --board 175c --lang pt --script pt-capitals --out shots/175c/
#   tools/sim.sh --board 175 --lang pt --script pt-capitals --out shots/175/
